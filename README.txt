# Site do Residencial Joana

## Como usar
1. Abra o ficheiro `script.js`.
2. Troque `244900000000` pelo número real de WhatsApp do hotel, sem `+`, espaços ou parênteses.
3. Em `index.html`, altere telefone, e-mail, localização, preços e textos que quiser.
4. Quartos e preços configurados: Solteiro 25.500 Kz; Casal 31.500 Kz; Casal Maior 40.500 Kz; Solteiro Maior 28.500 Kz; Duplo 40.500 Kz; Casal K 35.500 Kz.
5. As imagens atualmente vêm do Unsplash. Para usar fotos próprias, substitua as URLs no `style.css`.
5. Abra `index.html` no navegador para testar.

## Como publicar gratuitamente
Uma opção simples é usar GitHub Pages ou Netlify. O site é estático e não precisa de servidor próprio.

## Reservas
Esta versão não confirma disponibilidade automaticamente. O cliente preenche o formulário e o site abre o WhatsApp com todos os dados. O hotel confirma a reserva manualmente.

## Próximo passo
Se quiser reservas com calendário, disponibilidade real por quarto e painel de administração, será necessário adicionar uma base de dados/backend ou integrar um serviço de reservas.
